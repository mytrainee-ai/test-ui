# Math Page Vision Lab

Локальное учебное приложение: показывает, как Vision LLM читает **одну** страницу учебника математики и превращает её в структурированный JSON и Markdown с формулами LaTeX. Можно указать OpenAI или другой сервис, совместимый с OpenAI Responses API для изображений и структурированного вывода. Интерфейс на русском языке. PDF обрабатывается как изображение выбранной страницы; текст напрямую из PDF не извлекается.

## Требования

- Python 3.12 или новее (деплой на Ubuntu 26.04 проверен с Python 3.14)
- Доступ к API выбранного провайдера и модель, принимающая изображения
- Интернет для запроса к API

## Установка: Windows PowerShell

В каталоге проекта выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если PowerShell запрещает активацию скриптов, можно запускать команды через `.\.venv\Scripts\python.exe -m pip ...` и `.\.venv\Scripts\python.exe -m streamlit run app.py` без активации.

## Установка: Linux/macOS

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

## Настройка API в `.env`

Для прямого OpenAI:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4.1-mini
```

В `.env.example` указан стандартный адрес OpenAI. Если оставить `OPENAI_BASE_URL` пустым, приложение также использует этот адрес. Для ProxyAPI:

```env
OPENAI_API_KEY=ключ_ProxyAPI
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
OPENAI_MODEL=openai/gpt-4.1-mini
```

Для другого совместимого сервиса укажите его базовый адрес и идентификатор модели по документации сервиса. Он должен поддерживать `/responses`, изображения и структурированный вывод по JSON-схеме. Приложение не подменяет модель автоматически. Настоящий `.env` и ключи не добавляйте в Git.

## Запуск

После активации `.venv`:

```bash
streamlit run app.py
```

Откройте адрес, который напечатает Streamlit (обычно `http://localhost:8501`). Загрузите JPG, JPEG, PNG или PDF до 15 МБ. Для PDF выберите страницу, посмотрите исходное изображение и нажмите **«Распознать страницу»**. Результат доступен во вкладках «Просмотр», «Markdown» и «JSON». Кнопки скачивания сохраняют данные без нового API-запроса. Результаты на сервере не записываются. При смене файла или страницы старый результат в интерфейсе сбрасывается.

Для развёртывания на Ubuntu с регистрацией и входом через email и пароль см. [инструкцию по деплою](deploy/README.md). Локальный запуск Streamlit напрямую не включает проверку входа; на сервере её обеспечивает Nginx вместе с `auth_service.py`.

## Что происходит при распознавании

1. Pillow проверяет изображение, а PyMuPDF превращает только выбранную страницу PDF в PNG с разрешением 200 DPI.
2. Приложение отправляет изображение и инструкцию одним основным запросом через OpenAI SDK и Responses API на адрес из `OPENAI_BASE_URL`.
3. Для структурированного вывода передаётся Pydantic-схема. Приложение дополнительно проверяет уникальность `id` и непрерывный порядок `order`. Если сервис не поддерживает этот формат ответа, приложение покажет ошибку.
4. Markdown строится локально из **того же** проверенного JSON. Второго запроса к модели нет.

Пример сокращённого JSON:

```json
{
  "document": {"filename": "page.png", "page_number": 1, "language": "ru"},
  "elements": [
    {"id": "element_001", "order": 1, "type": "heading", "text": "Квадратные уравнения", "latex": null, "description": null},
    {"id": "element_002", "order": 2, "type": "formula", "text": null, "latex": "ax^2+bx+c=0", "description": null}
  ]
}
```

## Ограничения и данные

Это эксперимент по извлечению информации, а не проверка математической правильности. Модель может ошибиться в символах, формулах, таблицах, рисунках и порядке чтения. Она не должна самостоятельно решать отсутствующие на странице задачи, но результат всё равно стоит сверять с исходником. Поддерживается одна страница за запрос; пакетной обработки и локальной базы данных нет.

**Изображение выбранной страницы отправляется во внешний API выбранного провайдера** и может обрабатываться согласно его условиям. Запросы к API могут стоить денег. Приложение не сохраняет загруженный документ автоматически и не отправляет остальные страницы PDF.
