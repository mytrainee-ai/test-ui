# Math Page Vision Lab

Локальное учебное приложение: показывает, как Vision LLM читает **одну** страницу учебника математики и превращает её в структурированный JSON и Markdown с формулами LaTeX. Можно выбрать OpenAI или другого провайдера с OpenAI-совместимым API для изображений. Интерфейс на русском языке. PDF обрабатывается как изображение выбранной страницы; текст напрямую из PDF не извлекается.

## Требования

- Python 3.12
- Доступ к API выбранного провайдера и модель, принимающая изображения
- Интернет для запроса к API

## Установка: Windows PowerShell

В каталоге проекта выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если PowerShell запрещает активацию скриптов, можно запускать команды через `.\.venv\Scripts\python.exe -m pip ...` и `.\.venv\Scripts\python.exe -m streamlit run app.py` без активации.

## Установка: Linux/macOS

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

## Выбор провайдера в `.env`

Для OpenAI (по умолчанию):

```env
LLM_PROVIDER=openai
LLM_API_KEY=ваш_ключ
LLM_MODEL=gpt-4.1-mini
```

Для другого провайдера, который поддерживает OpenAI-совместимый **Chat Completions API с изображениями**:

```env
LLM_PROVIDER=openai_compatible
LLM_API_KEY=ключ_этого_провайдера
LLM_MODEL=имя_его_vision_модели
LLM_BASE_URL=https://provider.example/v1
```

Адрес `LLM_BASE_URL` и имя модели возьмите из документации выбранного провайдера. Приложение не подменяет модель автоматически. Для OpenAI также продолжают работать прежние `OPENAI_API_KEY` и `OPENAI_MODEL`, если новые переменные не заданы. Настоящий `.env` и ключи не добавляйте в Git.

## Запуск

После активации `.venv`:

```bash
streamlit run app.py
```

Откройте адрес, который напечатает Streamlit (обычно `http://localhost:8501`). Загрузите JPG, JPEG, PNG или PDF до 15 МБ. Для PDF выберите страницу, посмотрите исходное изображение и нажмите **«Распознать страницу»**. Результат доступен во вкладках «Просмотр», «Markdown» и «JSON». После успешного распознавания UTF-8 файлы `outputs/math_page.md` и `outputs/math_page.json` автоматически записываются в проект. Следующее распознавание перезаписывает их. Кнопки скачивания сохраняют те же данные без нового API-запроса. При смене файла или страницы старый результат в интерфейсе сбрасывается.

## Что происходит при распознавании

1. Pillow проверяет изображение, а PyMuPDF превращает только выбранную страницу PDF в PNG с разрешением 200 DPI.
2. Приложение отправляет изображение и инструкцию одним основным запросом. Для `openai` используется Responses API со структурированным выводом. Для `openai_compatible` используется Chat Completions API с изображением в data URL; провайдеру предлагается вернуть JSON.
3. Ответ проверяется Pydantic-схемой. Приложение дополнительно проверяет уникальность `id` и непрерывный порядок `order`. У совместимого провайдера соблюдение схемы зависит от модели; если она вернула невалидный JSON, приложение покажет ошибку.
4. Markdown строится локально из **того же** проверенного JSON. Второго запроса к модели нет. Папка `outputs/` исключена из Git.

Пример сокращённого JSON:

```json
{
  "document": {"filename": "page.png", "page_number": 1, "language": "ru"},
  "elements": [
    {"id": "element_001", "order": 1, "type": "heading", "text": "Квадратные уравнения", "latex": null, "description": null},
    {"id": "element_002", "order": 2, "type": "formula", "text": null, "latex": "ax^2+bx+c=0", "description": null}
  ]
}
```

## Ограничения и данные

Это эксперимент по извлечению информации, а не проверка математической правильности. Модель может ошибиться в символах, формулах, таблицах, рисунках и порядке чтения. Она не должна самостоятельно решать отсутствующие на странице задачи, но результат всё равно стоит сверять с исходником. Поддерживается одна страница за запрос; пакетной обработки и локальной базы данных нет.

**Изображение выбранной страницы отправляется во внешний API выбранного провайдера** и может обрабатываться согласно его условиям. Запросы к API могут стоить денег. Приложение не сохраняет загруженный документ автоматически и не отправляет остальные страницы PDF.
